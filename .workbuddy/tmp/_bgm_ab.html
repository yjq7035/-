Snowfall v1

A 小调 / 72 BPM / 26.7 秒循环。旋律用随机数从音阶里挑音，不看当前和弦； 音域冲到 A4–E6；铃音带 2.01×、4.71× 这类非谐波泛音；琶音每小节 8 个音不停。

为什么不是"下载那首 snowfall"：流传最广的 Øneheart × reidenshi 版本是有版权的商业录音， 打进小游戏包体再上传发布属于侵权。但它的公开分析数据可用，v2 就是按那套参数做的：
原曲 = F 大调 / 4-4 / ~95 BPM / 和弦进行 I△7–ii7–vi9（Fmaj7–Gm7–Dm9）/ 旋律音域 C4–C6。 v2 采用同一套和声语言与音域，只把速度放到 76 BPM 以适配塔防的长时间循环。

一个失败的度量（如实记录）：我本想用一个心理声学"粗糙度"模型量化"刺耳"，结果它给出的排序 与听感相反（判 v2 更糙）。原因是它实际上度量的是"低频区互相贴近的分音有多少"= 浑浊度， 而刺耳的主因是和声冲突——那是乐谱层面的事，频谱指标测不出来。 该模型已降级为诊断项、不参与判定，标定失败的过程写在 tools/measure-timbre.py 的注释里，免得以后有人再被它骗。

所以"刺耳"的最终判据只有你的耳朵 —— 上面两个播放器就是为这个准备的。 如果 v2 还是不对，告诉我具体哪里不对（太闷 / 旋律难听 / 引子太长 / 想更接近原曲速度）， 这些都是 tools/make-snowfall.py 里可调的参数，改完重跑即可。
